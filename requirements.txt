# ---------------------------------------------------------------------------
# Pairing-Based Cryptography (Global — NOT proposed-scheme-only)
# ---------------------------------------------------------------------------
# CORRECTED 2026-08-03: pairing was previously listed under "proposed scheme
# only". That was wrong. Ref[41] (thingom_pq_abse) is a BASELINE and is itself
# pairing-based: References/Ref[41].txt:510-513 defines e : I1 x I1 -> I2 over
# two cyclic groups, with security resting on DBDH (Ref[41].txt:280-300).
# A pairing library is therefore required to run a baseline, not just ours.
#
# Ref[41] publishes a TYPE-I (symmetric) pairing. Only charm-crypto provides a
# symmetric curve (SS512); petrelic offers Type-III curves only. Reportable
# Ref[41] runs therefore REQUIRE charm-crypto, which is Linux-only.
# See Experiment Configuration/crypto.yaml -> thingom_pq_abse.pairing
#
# charm-crypto>=0.50            # Type-I (SS512) + Type-III — LINUX ONLY
#                               # Required for reportable Ref[41] runs.
#                               # Not on PyPI as a wheel; install separately:
#                               #   pip install charm-crypto
# petrelic>=0.1.5                # Type-III only. Cross-platform. DEVELOPMENT
                                # fallback for Ref[41] — NOT reportable.
                                # Not resolvable via PyPI as of 2026-08-23
                                # ("No matching distribution found for
                                # petrelic") — pinning it here made a hard
                                # requirements.txt install abort provision.sh
                                # before it ever reached charm-crypto, even
                                # though provision.sh's own "Pairing backends"
                                # step already installs it best-effort with a
                                # `|| echo ... (dev fallback only)` guard.
                                # Left commented rather than deleted so the
                                # intent (Type-III dev fallback) stays
                                # documented; that step is the sole installer.
